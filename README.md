# Interactive Ocean Animation

A self-contained browser scene exploring CSS animation, SVG illustrations, pointer interaction, and animated fish in a stylized underwater environment.

**Status:** Creative front-end experiment. No external application framework or live data integration is required.

## Features
- SVG marine-creature illustrations.
- CSS-based floating motion.
- Animated bubbles and small fish.
- Pointer-following light effect.
- Full-screen scene layout.

## Run
Open `index.html` in a modern browser.

## Project structure
- `index.html` — HTML, CSS animation, SVG illustrations, and browser interaction.

## Limitations
- Visual effects and animation are browser-based.
- No backend or automated tests.
- Interaction and layout are intended as a small creative demo.

## Roadmap
- Add touch-friendly interaction.
- Respect reduced-motion preferences.
- Improve responsive layout and accessibility.
- Separate styles and script into dedicated files if the project grows.
